# Sales Performance & Customer Analysis

**Microsoft Excel | Academic Group Project**

## Project Overview

This project focuses on sales performance and customer analysis using Microsoft Excel.

The project uses a simulated dataset to explore business information and present results through Excel dashboards.

## Project Objectives

- Explore sales performance.
- Organise and prepare business data.
- Examine customer information.
- Present business information through dashboard visualisation.

## My Contribution

My main responsibility in this group project was **data preparation**, including:

- **Data Entry:** Entering the provided data into Microsoft Excel.
- **Data Cleaning:** Organising and arranging the dataset.
- **Data Organisation:** Preparing the data for further analysis by the project team.

## Tools Used

- Microsoft Excel

## Skills Demonstrated

- Data Entry
- Data Cleaning
- Data Organisation
- Teamwork

## Dataset Disclaimer

The dataset used in this project is simulated and was prepared for academic purposes. It does not represent actual business transactions.
